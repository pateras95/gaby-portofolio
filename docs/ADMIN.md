# Admin (`/admin`) — οδηγός

Το `/admin` είναι ένα μικρό CMS: επεξεργάζεσαι το περιεχόμενο των config σε φόρμες, βλέπεις preview και κάνεις export τα αρχεία πίσω στο `src/config/`.

## Μπαίνω στο admin
- Τοπικά: `npm run dev` → http://localhost:5173/admin
- Live: `https://<το-domain-σου>/admin`
- Γράφεις τον κωδικό. Μένεις συνδεδεμένος μέχρι να κλείσεις το tab.

## Άλλαξα / ξέχασα / έχασα τον κωδικό
Δεν χρειάζεται να ξέρεις τον παλιό — απλά ορίζεις νέο. Από τον φάκελο του project:

```bash
# δικός σου κωδικός
npm run admin:password -- "ο νέος κωδικός"

# ή τυχαίος (τυπώνεται μία φορά στο terminal)
npm run admin:password
```

Το script ξαναγράφει το `src/admin/auth.config.js`. Μετά:

```bash
git add src/admin/auth.config.js
git commit -m "new admin password"
git push          # και deploy όπως συνήθως, για να ισχύσει στο live site
```

Ο νέος κωδικός δουλεύει στο live site μόνο αφού γίνει deploy. Μέχρι τότε ισχύει ο παλιός εκεί.

### Τι αποθηκεύεται
Στο `auth.config.js` μπαίνει μόνο ένα salted hash (PBKDF2, 310.000 γύρες), **όχι** ο κωδικός. Γι' αυτό δεν μπορεί να ανακτηθεί — μόνο να αλλάξει.

### Όρια της προστασίας
Το site είναι στατικό (χωρίς server), άρα ο έλεγχος γίνεται στον browser. Κρατάει έξω τυχαίους επισκέπτες, αλλά δεν είναι πραγματική ασφάλεια: χρησιμοποίησε μακρύ κωδικό. Το admin δεν μπορεί να αλλάξει το live site — οι αλλαγές γίνονται μόνο με export + commit. Για πραγματική προστασία: Cloudflare Access πάνω στο `/admin*`.

## Ροή δουλειάς για αλλαγή περιεχομένου
1. Μπες στο `/admin`, διάλεξε ενότητα αριστερά, άλλαξε τα πεδία (το preview δεξιά ανανεώνεται μόνο του).
2. Πάτα **Export** → κατέβασε τα αρχεία με την ένδειξη *changed*.
3. Αντικατέστησε τα ίδια αρχεία στο `src/config/` (`site`, `home`, `projects`, `captions` `.config.js`).
4. `npm run build` (ή απλά `npm run dev` για έλεγχο), μετά commit + push.

Οι αλλαγές σου αποθηκεύονται αυτόματα **στον browser** ως draft (localStorage), ώστε να μην χάνονται αν κλείσεις το tab. Δεν είναι στο repo ώσπου να κάνεις export. Αν αλλάξεις browser/υπολογιστή, κάνε export και **Import** των αρχείων (κουμπί *Import*) για να συνεχίσεις.

## Συμβουλές
- **Post σε video / δείγμα:** στο πεδίο `ref` βάλε ολόκληρο το URL του post (Instagram, TikTok, YouTube…). Κάτω από το πεδίο φαίνεται ✓ / ✗ αν βρέθηκε.
- **Comments:** το export κρατά μόνο το header σχολίων κάθε αρχείου και τα ονόματα ομάδων στα captions· τα σχόλια μέσα στα αρχεία δεν διατηρούνται.
- **Discard / Discard all:** επαναφέρει τα αρχεία του project (σβήνει το draft).
- Αν αλλάξεις τα αρχεία στο `src/config/` με το χέρι ενώ έχεις draft, το admin σε ειδοποιεί και μπορείς να φορτώσεις την έκδοση του project.
